# v0.1.0-beta

First public **beta** of `dotf` — the native Go provisioning CLI for this dotfiles
repository. This release marks the cutover from the legacy bash/Ansible bootstrap to a
single, checksum-verified binary distributed via GitHub Releases.

> **Beta scope.** `dotf` is feature-complete for the provisioning path (sysconfig →
> packages → symlinks → firewall) but the package manifest is still a skeleton. Expect
> rough edges; pin to a tag rather than tracking `latest` if you need stability.

## Highlights

- **`dotf apply` is the entry point.** `bootstrap.sh` is now a ~45-line POSIX shim that
  downloads the checksum-verified `dotf` binary from GitHub Releases and execs
  `dotf apply` — one ordered pass over sysconfig → packages → symlinks → firewall with
  `--headless`/`--force` flag-and-env parity, an opt-in `--snapper` pre-apply snapshot,
  and a run-wide non-fatal failure summary.
- **Native symlink engine.** `dotf link` (`internal/symlink`) provisions the symlink set
  natively with `--dry-run`, `--backup`, `--linux-desktop`, and post-apply validation.
  The Ansible `playbooks/symlinks.yml` is retired but retained one release for rollback.
- **Per-OS system config.** `dotf sysconfig` (`internal/sysconfig`) owns
  hostname/timezone/locale/shell/firewall across supported Linux distros and macOS.
- **Multi-backend install engine.** `dotf install` provisions across Homebrew, apt, dnf,
  pacman/AUR, and zypper.
- **Rich CLI ergonomics.** Global and per-command help (`--help`/`-h`), plus
  `dotf completion` for bash, zsh, and fish (`--install`/`--force`/`--dry-run`).

## Commands

`version`, `platform`, `plan`, `install`, `status`, `diff`, `link`, `sysconfig`,
`apply`, `completion`, and `help`.

## Breaking Changes

- **`bootstrap.sh` no longer provisions in-process.** It is now a download-and-exec shim
  for the `dotf` binary; the bash provisioning path is retired as the entry point (the
  `bin/install-*.sh` installers are retained). Re-run `./bootstrap.sh` to fetch the new
  binary.

## Install

The release workflow (GoReleaser) publishes static binaries for **linux, darwin, and
windows** on **amd64 and arm64**, plus `checksums.txt`. The bootstrap shim resolves
`/releases/latest/download/dotf_<os>_<arch>.tar.gz` automatically:

```bash
git clone https://github.com/yandy-r/dotfiles.git ~/.config/dotfiles
cd ~/.config/dotfiles
./bootstrap.sh
```
