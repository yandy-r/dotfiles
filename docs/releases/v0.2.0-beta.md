# v0.2.0-beta

Second **beta** of `dotf` — the native Go provisioning CLI for this dotfiles
repository. This release turns the provisioning path from a scaffold into a working
end-to-end setup: the package manifest is populated, the legacy `bin/install-*.sh`
installers and system-setup steps are wired into `dotf apply`, and the interactive
workflow now aborts gracefully.

> **Beta scope.** `dotf` now provisions the real daily-driver toolset (the package
> manifest is no longer a skeleton) across the full pass — sysconfig → packages →
> symlinks → firewall — with Homebrew bootstrapped ahead of packages and legacy
> installers available behind opt-in intents. Still pin to a tag rather than tracking
> `latest` if you need stability.

## Highlights

- **Provisioning parity — legacy installers wired into the manifest.** `dotf apply` and
  `dotf install` now bootstrap Homebrew before the packages phase, provision the
  daily-driver toolset via the `dev`/`base` intents, and wrap the retained legacy
  `bin/install-*.sh` installers plus system-setup steps (XDG/dev dirs, TPM, sessionizer,
  GNU utils) behind opt-in `runtimes`/`ai`/`cloud`/`git-tools`/`system` intents via the
  `custom-script` backend — full provisioning parity with the old bash path (#32, #33,
  #35).
- **The package manifest is populated.** `manifest/packages.toml` now carries the real
  modern-CLI toolset provisioned via the native `pkg` backend, with toolchain-tool
  validation rejecting malformed entries at load time (#26).
- **Graceful interactive abort.** Ctrl+C — and Esc in the `plan`/`apply` guided wizard —
  exits cleanly with `dotf: aborted` and exit **130** (the Unix SIGINT convention).
  Interrupt handling is scoped to the prompts; post-confirmation execution keeps default
  SIGINT behavior (#37).
- **Forge-aware bootstrap.** `bootstrap.sh` gains a `--repo` flag and forge-aware release
  downloads, so the shim can resolve the `dotf` binary from a chosen fork or forge.

## Install

The release workflow (GoReleaser) publishes static binaries for **linux, darwin, and
windows** on **amd64 and arm64**, plus `checksums.txt`. The bootstrap shim resolves
`/releases/latest/download/dotf_<os>_<arch>.tar.gz` automatically:

```bash
git clone https://github.com/yandy-r/dotfiles.git ~/.config/dotfiles
cd ~/.config/dotfiles
./bootstrap.sh
```
